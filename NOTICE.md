  **Captive DreamDev**. This repository is an unofficial, non-commercial fan translation.
- This repository contains **no game files**. It contains only:
  - the translator's own Simplified Chinese text,
  - a short structural descriptor (row names, cell counts) needed to rebuild the csv,
  - SHA-1 fingerprints of the original Russian strings (for update matching).
- No game executable, no .assets file, no audio, no image, no save file is distributed here.
- Installation is done locally by the user, by copying a text file into their own game folder.
