# 未覆盖的预制体文字（已知限制）

## 现象

游戏里绝大多数文本走 Txt.Load_text()，从 StreamingAssets/Localizations/zh.csv 读取，
本补丁已 100% 覆盖。

但有一小部分文字是**直接写在预制体/场景里的 TMP 文本组件**，没有对应的 text_id，
运行时不会被本地化系统改写。这些字符串目前仍是英文（少数是俄文）。

已知约 **45 处**，典型例子：

    Settings / Save game / Loading… / Victory! / Autosave / Language / Bad Girls / Tool team

## 为什么不放进主补丁

因为这些文字在 .assets 序列化文件里，要改必须重写二进制资源，风险与维护成本都高得多：

- 资源文件有几十上百 MB，改一个字符串要重新序列化整个文件；
- 游戏一更新，改过的资源会被整体替换，补丁必须重打；
- 一旦序列化出错，游戏会直接崩溃。

## 后续方案（计划）

1. **资源补丁**：用 UnityPy 读取游戏自己的 .assets，按字符串内容定位并用中文替换，
   保存前做结构校验。缺点：体积大、每次更新都要重跑。
2. **运行时插件**：写一个极小的 BepInEx / MelonLoader 插件，在 TMP 文本赋值时做字符串替换。
   优点：不碰资源文件、更新后仍可用；缺点：需要用户额外装插件框架。

倾向方案 1（不改运行环境），但要先确认这 45 处里有多少是玩家真的会看到。

## 你可以做什么

如果你在游戏里看到**中文界面中夹着英文单词**（例如某个按钮写着 Settings），
请截图 + 记下大概位置，开 issue。数量够多时再决定做资源补丁。
