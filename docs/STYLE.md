# 译名与体例

本补丁以**俄文原文**为准重译，官方英文只用来借"队名感 / 语气"，不借事实与增译。

## 体例

- **不用"您"**：角色之间一律"你"。
- **括号保留**：俄文（Хмуро）→ （皱眉）。
- **换行符**：[2525] 原样保留，表示换行。
- **占位符**：{0}、[s0]、[tp]、[pt] 一律原样，不得替换成具体内容。
- **引号**：中文用「」和""，不使用 ASCII 双引号（构建时会自动转换）。
- **队伍名 2–6 字**，避免"XX队伍"这种 team-team 冗余。
- **粗口不净化**：原文多粗就多粗；只在正常语境下不主动加辣。

## 语体分层

| 文本 | 处理 |
|---|---|
| 系统 UI | 短、名词或动宾、不加语气词、同组对齐 |
| 主持人解说 | 短句 + 感叹号 + 观众视角 |
| 角色对白 | 口语化，长句按气口切 |
| 世界观文献 | 书面语，允许长句与密集术语 |
| 情色场景 | 直白但不堆砌同义词；UI 用中性词，对白用口语词 |
